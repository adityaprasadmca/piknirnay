# Features

- Public landing page, how-it-works, language choice, and guest entry.
- Farmer profile with Maharashtra location, soil, water, optional pH, and acre/guntha conversion.
- Kharif/Rabi and cautious/balanced/ambitious selection.
- Deterministic sample crop cards with cost, return range, loss chance, sowing window, and confidence.
- Two-crop comparison and recommendation reasons with hypothetical scenarios.
- Sample sowing calendar, mandi price chart, and seven-day weather view.
- Local expert question submission and sample status/response tracking.
- Farmer history and preferences persisted in localStorage.
- Expert case queue and sample admin dashboard, crop library, data freshness, sources, users, models, and activity views.
- Responsive layouts for desktop and mobile; Vercel SPA route fallback.
